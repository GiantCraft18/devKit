# DevKit — Developer Toolkit

Бесплатный набор инструментов для разработчиков с тёмным киберпанк-интерфейсом. Русский и английский языки. Нет регистрации, аккаунтов, базы данных или собственного сервера.

## Инструменты

- **JSON Studio** — проверка синтаксиса, форматирование и сжатие JSON.
- **Color Lab** — выбор HEX-цвета, значения RGB/HSL, CSS-градиент и копирование CSS.
- **Code Formatter** — базовое форматирование HTML, CSS и JavaScript. Это лёгкий форматтер на эвристиках, а не замена Prettier/ESLint.
- **Password Lab** — генерация паролей через Web Crypto API с выбором длины и наборов символов.
- **Base64 Studio** — UTF-8-safe кодирование и декодирование Base64.
- **QR Generator** — создание и скачивание QR-кода PNG. Для этой функции нужна доступная CDN-библиотека QRCode.js; остальные инструменты не требуют внешних библиотек.

## Запуск локально

1. Скачайте ZIP и распакуйте его.
2. Откройте `index.html` в современном браузере.
3. Для QR-кодов потребуется интернет для загрузки QRCode.js с CDN. Остальные инструменты работают локально.

Если браузер ограничивает отдельные возможности при открытии через `file://`, запустите любой локальный статический сервер (например, расширение Live Server в VS Code). Сервер нужен только для локальной раздачи файлов, не для приложения.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий GitHub, например `devkit`.
2. Загрузите `index.html`, `README.md` и папку `assets` в корень репозитория. Сохраняйте структуру папок.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, нажмите **Save**.
6. Дождитесь публикации и откройте адрес вида `https://ВАШ-НИК.github.io/devkit/`.

## Приватность и безопасность

- Текст, JSON, цвета, пароли и Base64 обрабатываются в браузере; код не отправляет эти данные на собственный сервер.
- QRCode.js загружается с CDN при открытии страницы. Текст QR-кода передаётся в библиотеку в браузере, но не отправляется самим приложением на отдельный API.
- Не используйте сайт для обработки секретов на чужих или общедоступных устройствах.
- Генератор паролей использует `crypto.getRandomValues`; если API недоступен, выдаёт ошибку вместо небезопасного fallback.
- Цвета и форматтеры не загружают сторонние API. Google Fonts используется для внешнего шрифта; системные шрифты остаются fallback.

## Ограничения

- Форматирование JavaScript/HTML/CSS сделано простыми эвристиками и не является полноценным синтаксическим парсером. Для сложного кода используйте Prettier или ESLint.
- QR-функция зависит от доступности CDN `cdnjs.cloudflare.com`. Если библиотека не загрузилась, сайт покажет ошибку и не будет изображать успешную генерацию.
- QR download создаётся локально из результата в браузере.
